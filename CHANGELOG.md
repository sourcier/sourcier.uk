# Changelog

Notable user-facing changes to sourcier.uk are recorded here, newest first,
grouped by deployment date in `YYYY-MM-DD` format.

This changelog is inspired by [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
The site is continuously deployed and uses dates instead of versioned releases.
It does not use Semantic Versioning or an `Unreleased` section.

Tracking begins with the introduction of this file. Earlier changes have not
been reconstructed.

See [Contributing](CONTRIBUTING.md#changelog) for entry guidelines.
