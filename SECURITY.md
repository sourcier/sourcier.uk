# Security Policy

## Supported versions

This project is continuously deployed and does not maintain versioned releases.
Security fixes target the current code on `main` and the production site at
[sourcier.uk](https://sourcier.uk). Historical commits and independently deployed
forks are not maintained.

## Reporting a vulnerability

Please use GitHub's
[private vulnerability reporting](https://github.com/sourcier/sourcier.uk/security/advisories/new)
to report suspected vulnerabilities in this repository or the production site.
Do not disclose vulnerabilities in public issues, pull requests, or blog comments.

Include:

- The affected page, endpoint, or source file.
- Steps to reproduce, using a minimal proof of concept where possible.
- The potential impact and any relevant prerequisites.
- Redacted logs or screenshots, if helpful.

Do not include credentials, payment details, or other people's personal data.
Keep testing non-destructive: do not access other users' data, disrupt the site,
send unsolicited messages, or make real payments to demonstrate an issue.

## Handling reports

Reports are reviewed privately. The maintainer may request more information and
coordinate a fix and any public disclosure through the advisory. Please allow
time for investigation and remediation before publishing details.

This is a personally maintained project, with no guaranteed response or
resolution time and no bug bounty programme.

For ordinary bugs and feature requests, use
[GitHub issues](https://github.com/sourcier/sourcier.uk/issues).
